# Fun Tic-Tac-Toe project

I tried to make the code more structured and better than my last project by making more functions to make the code more streamlined

##Features
-Choose X or O for your symbol on the Tic-Tac-Toe board
-Tie Detector and Win Detector
-CPU chooses random sqaures

##How to run

Run:

```bash
python tic_tac_toe.py
```
